## 🔹 About the Activity

This activity focuses on using Artificial Intelligence (AI)-powered website development tools to create a functional and visually appealing business website. For this project, I developed **REDRIDE**, a vehicle-rental website designed to help customers explore available rental vehicles and submit booking inquiries online.

The website was designed for customers in **Davao City**, allowing them to browse different vehicles, compare rental rates, and choose between self-drive and with-driver services.

To establish a distinct brand identity, I used a **Formula 1-inspired design theme**, incorporating racing red, carbon black, white, silver, and dark gray. The overall appearance communicates speed, performance, convenience, and professionalism.

## 🎯 Learning Objectives

- Explore AI-powered tools for website development.
- Understand how prompts can guide website design and functionality.
- Apply design principles when developing a business website.
- Organize website content to improve user experience and navigation.
- Present products, services, and pricing information clearly.
- Develop problem-solving and adaptability when working with digital tools.

## 🚘 Website Overview

**REDRIDE** is a vehicle-rental website concept that provides customers with an accessible way to explore rental options and make booking inquiries.

### Main Website Features

| Feature | Description |
|---|---|
| **Vehicle Catalog** | Displays 10 rental vehicles with photos, specifications, and descriptions. |
| **Rental Pricing** | Presents daily rental rates for self-drive and with-driver options. |
| **Booking Inquiry Form** | Allows customers to submit rental inquiries. |
| **Rental Details** | Collects relevant information such as rental dates and preferred service. |
| **Contact Section** | Provides a way for customers to reach the business. |
| **Responsive Design** | Uses a modern layout intended to provide convenient browsing across devices. |

## 🎨 Design Concept and Theme

The website follows a Formula 1-inspired visual identity to create a modern automotive experience.

### Color Palette

| Color | Design Purpose |
|---|---|
| 🟥 **Racing Red** | Highlights important elements and represents speed and energy. |
| ⬛ **Carbon Black** | Creates a bold and premium automotive appearance. |
| ⬜ **White** | Improves readability and provides visual balance. |
| 🩶 **Silver** | Adds a sleek and modern appearance. |
| **Dark Gray** | Supports the overall racing-inspired aesthetic. |

The combination of these colors gives REDRIDE a sporty and professional appearance while keeping the website organized and easy to navigate.

## 💻 Development Tools and Process

The website was developed with the assistance of AI-powered website development platforms.

### Tools Used

- **Replit** – Initially explored as the platform for developing the website.
- **Lovable** – Used as the alternative platform after Replit did not work as expected.
- **AI Prompting** – Used to communicate the website concept, design preferences, features, and requirements to the development tool.

### Development Experience

During the development process, I initially attempted to use Replit. However, it did not work as expected, which affected my progress. Instead of stopping the project, I explored another platform and continued the development using Lovable.

This experience demonstrated that AI tools can make website development more accessible, but the process may still involve technical difficulties, adjustments, and alternative approaches.

## 💡 Learning Reflection

Through this activity, I learned how AI-powered platforms can assist in developing a business website even without having extensive programming knowledge. By providing clear instructions and design preferences, I was able to create a website concept that presents services, rental options, and booking information in an organized manner.

One of the challenges I encountered was using Replit, which did not work as expected. Because of this, I decided to explore another platform, Lovable, to continue working on the project. This taught me the importance of adaptability, resourcefulness, and finding alternative solutions when working with technology.

I also realized that developing a website involves more than simply making it visually appealing. It is important to consider the user's experience, accessibility of information, organization of content, and functionality of its features.

Overall, this activity improved my understanding of AI-assisted website development and showed me how digital tools can be applied to create practical business solutions.
