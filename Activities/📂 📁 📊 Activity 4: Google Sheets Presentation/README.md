## 🔹 About the Activity

This activity focuses on **Google Sheets**, a web-based spreadsheet application developed by Google. It explores how spreadsheets can be used to organize, calculate, analyze, and present information through rows, columns, formulas, functions, and various data management features.

The presentation discusses the essential features of Google Sheets, its interface, and its practical applications in academic, personal, healthcare, and workplace settings. It also highlights how cloud-based accessibility and collaboration make spreadsheet management more convenient and efficient.

## 🎯 Learning Objectives

- Understand the definition, purpose, and interface of Google Sheets.
- Identify spreadsheet components such as rows, columns, cells, cell references, and the formula bar.
- Differentiate formulas from functions and understand their applications.
- Explore common spreadsheet functions for calculations and data analysis.
- Understand sorting, filtering, conditional formatting, and data validation.
- Recognize the importance of collaboration, sharing permissions, version history, and automatic saving.
- Identify practical applications of Google Sheets in education, personal activities, healthcare, and business.

## 🧮 Common Google Sheets Functions

The presentation introduces several useful functions and their purposes:

| Function | Purpose | Example |
|---|---|---|
| `SUM` | Adds numbers | `=SUM(B2:B10)` |
| `AVERAGE` | Calculates the mean | `=AVERAGE(B2:B10)` |
| `COUNT` | Counts cells containing numbers | `=COUNT(B2:B10)` |
| `MAX` | Finds the highest value | `=MAX(B2:B10)` |
| `MIN` | Finds the lowest value | `=MIN(B2:B10)` |
| `IF` | Returns a result based on a condition | `=IF(B2>=75,"Passed","Failed")` |
| `COUNTIF` | Counts cells that meet a condition | `=COUNTIF(B2:B10,">=75")` |
| `SUMIF` | Adds values that meet a condition | `=SUMIF(A2:A10,"Nursing",B2:B10)` |
| `ROUND` | Rounds a number | `=ROUND(B2,2)` |

## 💡 Learning Reflection

Through this activity, I gained a better understanding of how Google Sheets can be used beyond basic data entry. I learned how its formulas and functions simplify calculations, while sorting, filtering, and charts help organize and interpret information more effectively.

These applications demonstrate how digital productivity tools can contribute to more efficient and organized work processes.

Overall, this activity strengthened my understanding of spreadsheet management and showed me how Google Sheets can be a valuable tool in both academic and professional environments.
